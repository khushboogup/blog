<h6>Recipe Blog Walthrough</h6>

Recipe blog for **My Favourite Recipe** with HTML.

<h6>File Structure</h6>

```
Blog/
├── recipes/
│   ├── momo.html
│   └── thecha.html
|   └── mint.html
|   └── tomato.html
├── images/
│   ├── momo.jpeg
│   └── thecha.jpg
|   └── mint.jpg
|   └── tomato.jpg
└── index.html  

```

## Recipes Included

- **Momo** — Steamed dumplings
- **Tomato Soup** — Classic comfort soup
- **Thecha** — Spicy green chilli chutney
- **Mint Chutney** — Fresh and tangy dip

## Images

All images are downloaded from free sources on Google and are used for personal/educational purposes only.

##  How to Run
If you are using text editor. Go on terminal write `open ./index.html`
